# Завдання 2

Обчислено визначений інтеграл функції:

```text
f(x) = x^2
```

на проміжку:

```text
[0, 2]
```

## Результати

Аналітичне значення:

```text
8 / 3 = 2.666667
```

Результат `scipy.integrate.quad`:

```text
2.666667
```

Результат методу Монте-Карло для `100000` випадкових точок:

```text
2.669494
```

Абсолютна похибка Монте-Карло:

```text
0.002827
```

## Висновок

Метод Монте-Карло дає результат, близький до аналітичного значення та до результату `quad`.

Невелика похибка виникає через випадковий вибір точок.

При збільшенні кількості точок точність методу Монте-Карло зростає.
