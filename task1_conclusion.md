## Greedy vs Dynamic Programming

### Greedy

Time: `O(n log n + k)`

Space: `O(n)`

Fast and simple. Uses little memory and may not give optimal result.

### Dynamic Programming

Time: `O(n * change)`

Space: `O(change)`

Slower and uses more memory always gives optimal result if solution exists.

### Conclusion

Greedy: faster, less memory, not always correct.

DP: slower, more memory, always correct.
